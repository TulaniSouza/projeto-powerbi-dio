# Módulo 06 - Projeto 02: Relatório de Vendas e Lucros com Data Analytics

Este repositório contém a entrega final do segundo projeto do Módulo 06 da **Formação Power BI Analyst da DIO**, consolidando conceitos avançados de modelagem visual, análise de dados e experiência do usuário (UX).

---

## Sobre o Projeto
O objetivo deste projeto foi integrar todas as frentes abordadas ao longo da formação para construir um dashboard gerencial executivo robusto e interativo. O relatório é composto por uma capa de entrada e três páginas analíticas altamente refinadas.

---

## Principais Recursos Implementados
1. **Página Inicial (Capa):** Design moderno desenvolvido com identidade visual personalizada, contendo o botão funcional *"Explorar análise"* para direcionar o usuário à navegação.
2. **Aba Vendas (Página 1):** Visão geral de KPIs de faturamento, segmentação por canal e produto, além de filtros temporais dinâmicos.
3. **Aba Detalhes (Página 2):** Análise detalhada da sazonalidade temporal (vendas por ano/semestre) e estudo de distribuição de frequência através de gráficos de *Buckets* (Histograma).
4. **Análise Top N (Página 3):** Aplicação de filtros avançados de *Top 3* (produtos e países) combinados com gráficos de dispersão (*Scatter Plot*) para cruzamento de métricas de lucro e volume de vendas.
5. **Navegabilidade Global:** Inclusão de botões de controle intuitivos (*Voltar*, *Avançar* e *Home*) em conjunto com o menu lateral vertical.
